## Design & outils

### Glisser une page web directement dans Figma
La nouvelle extension Chrome d'html.to.design capture une page entière à coller en Ctrl+V dans Figma, prête à éditer. [Sidebar](https://bit.ly/side-div6)

### Extend UI, un kit open source pour les apps documentaires
Composants React pour visionner PDF, DOCX, XLSX et CSV, gérer l'upload et la signature électronique. [Sidebar](https://www.extend.ai/ui)

### Vibe coder ou ingénieur logiciel
Le vibe coding excelle pour explorer, mais l'ingénierie commence quand le code généré doit être relu, possédé et modifié sans casse. [Sidebar](https://yusufaytas.com/vibe-coder-vs-software-engineer)

### Le vrai goulot, c'est décider quoi construire
Les agents ont rendu le code bon marché et exposé le seul problème qui restait : savoir quoi bâtir. [Sidebar](https://kasperjunge.com/blog/should-pms-code-with-agents/)

### Words of Type
Une encyclopédie multilingue des termes typographiques, à garder sous la main. [Sidebar](https://wiki.wordsoftype.com/)
